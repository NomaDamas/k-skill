# Security Policy

## Supported versions

Security fixes land on the latest released version of each package under
`packages/*` (published to npm as `@nomadamas/k-skill` and related packages)
and on the `main` branch of this repository. Older releases are not patched.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report privately through GitHub's
[private vulnerability reporting](https://github.com/NomaDamas/k-skill/security/advisories/new)
for this repository. Include the affected skill or package, reproduction steps,
and the impact you observed.

If you find a live credential in this repository, report it the same way so it
can be rotated before details become public.

## What to expect

We aim to acknowledge reports within 7 days and to coordinate a fix and
disclosure with the reporter.
