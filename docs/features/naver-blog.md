# 네이버 블로그 글쓰기 가이드

## 이 기능으로 할 수 있는 일

- 사용자가 준 주제·초안으로 네이버 블로그 글(제목·본문)을 작성
- ego lite 브라우저로 SmartEditor ONE에 입력
- 기본값 **비공개**로 발행 설정 후, 최종 발행 직전 승인을 받아 발행
- 목록은 `ol`/`ul` 대신 원형 숫자(①②③…)로 작성해 서식 깨짐 방지

## 먼저 필요한 것

- ego lite 설치와 온보딩 (`ego-browser skill`이 동작해야 함)
- 네이버 계정 로그인은 사용자가 직접 수행
- 개인 자격증명(아이디·비밀번호·쿠키·토큰) 입력·저장 없음

## 입력값

- 주제 또는 초안 텍스트
- 대상 블로그(선택), 카테고리·태그(선택)
- 공개 범위: 기본 비공개. 공개 발행은 명시 요청과 별도 승인이 필요

## 기본 흐름

1. 에이전트가 초안을 작성해 사용자에게 보여준다.
2. ego lite TaskSpace에서 블로그 글쓰기 화면을 연다.
3. 로그인이 필요하면 사용자에게 넘기고, 확인 후 같은 space를 이어서 쓴다.
4. 제목과 본문을 SmartEditor ONE에 입력하고 `ol`/`ul`이 생기지 않았는지 확인한다.
5. 공개 설정을 비공개로 지정하고 카테고리·태그를 채운다.
6. 최종 발행 직전에 대상 블로그·제목·공개 범위를 보여주고 승인을 받은 뒤 한 번만 발행한다.
7. 비공개로 저장되었는지 확인하고 결과를 보고한다.

## 서식 규칙

- 자동 목록(`ol`/`ul`, `1.`/`-`) 대신 원형 숫자 `①②③…`를 줄 앞에 일반 문단으로 쓴다.

## 주의할 점

- CAPTCHA·본인인증·2FA는 우회하지 않는다.
- 발행 결과가 불명확하면 재발행하지 말고 글 목록을 조회한다.
- 읽기·검색·이미지 수집은 [네이버 블로그 리서치](naver-blog-research.md)를 사용한다.
