# 한국 채권 종목 조회·비교

`korean-bond-search`는 SEIBro의 채권 정보를 종목명·발행사·ISIN으로 검색해 발행조건, 잔액, 옵션을 같은 형식으로 비교하고 상세 조회한다. 조회한 값마다 출처와 확인시각을 표시하는 읽기 전용 스킬이다. GS Quant의 Instrument/Data 구조화 방식에서 영감을 받아 표준 Bond Instrument 필드를 설계했으며, 코드를 복제하거나 공식 제휴·연계를 주장하지 않는다.

기본 결과는 발행사·ISIN·만기·표면금리·잔액·옵션을 비교하는 표와 다음 선택 안내를 포함한 한국어 채팅이다. 정규화 JSON은 자동화·검증이 필요할 때만 `--format json`으로 요청한다.

## 지원 범위

- 일반 회사채, 금융채, 특수채, 국채·지방채, ABS
- 발행일·만기일·표면금리·발행금액·발행잔액
- 공모/사모, 선후순위, 보증, 상장 여부
- CALL/PUT과 CB/EB/BW 식별
- UTF-8·CP949 JSON/CSV/TSV 및 표 형태 HTML 내보내기

실시간 호가·Bid/Ask·YTM·신용등급 자체 판정·적정 스프레드·매매 추천은 범위 밖이다.

## 안정성 원칙

SEIBro WebSquare 화면은 단순 HTTP 요청에서 오류 안내나 빈 문서를 반환할 수 있어, HTTP 200만으로 성공을 판정하지 않는다. 브라우저에서 실제 결과를 확인하거나 내려받은 파일을 표준 라이브러리 helper로 파싱한다. 테스트·임의 입력은 실제 SEIBro 조회 결과로 제시하지 않는다. 누락값은 `null`로 두며 다른 값으로 추정하지 않는다. 원천 장애·빈 결과·파싱 실패를 서로 다른 상태로 반환한다. 외화나 통화가 확인되지 않은 금액은 KRW로 표시하지 않는다.

## 대화 흐름

정확한 ISIN이면 바로 상세 조회한다. 발행사나 별칭만 주어 후보가 많으면 최대 5개를 만기순으로 보여 주고 만기·회차·ISIN을 추가로 받는다. 상세 조건과 확인된 옵션 일정은 사용자가 채권을 선택한 뒤 펼친다. CALL은 매도청구권, PUT은 사채권자의 조기상환청구권으로 구분하며 문맥이 모호하면 미확인으로 둔다.

`--observed-at`만 지정한 시각은 원천 확인 여부가 검증되지 않은 입력값으로 표시한다. 실제 원천 화면과 입력 자료를 대조한 경우에만 `--observed-at ... --verified-source`를 함께 지정해 SEIBro 출처와 원천 확인시각을 표시한다. 시각을 생략하면 입력 파일 수정시각을 대체값으로 표시한다. 로컬 디렉터리 경로는 출력 메타데이터에 노출하지 않는다. 금액 표시는 조·억·만 단위로 나누어 원 단위까지 보존한다.

같은 ISIN에 서로 다른 발행조건 레코드가 있으면 임의로 선택하지 않고 충돌로 보고한다. CSV/HTML의 중복 헤더나 행 열 수 불일치는 레코드를 조용히 버리지 않고 파싱 실패로 처리한다.
ISIN 체크디지트와 발행일·만기일 순서도 확인한다. 검증할 수 없는 종목코드나 발행일이 만기일 뒤에 오는 레코드는 정상 종목으로 내보내지 않는다.
