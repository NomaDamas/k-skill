# K-Skill directory bundle privacy notice

This notice applies only to the `k-skill-directory` bundle and its `korean-writing-editor` skill. It does not describe the separate K-Skill CLI, the full local marketplace bundle, the k-skill-proxy service, or any host model provider.

## What the directory bundle handles

The bundle contains static instructions. It processes only the Korean text that a user explicitly provides in the current conversation. It does not access files, mailboxes, accounts, device data, credentials, external websites, a proxy server, or a NomaDamas database. It contains no telemetry, hooks, executable helpers, or background jobs.

NomaDamas does not receive or retain the text through this bundle. The host model and chat product may process or retain the conversation under their own privacy policies and controls. Users should review those policies and use their deletion and history controls.

## Data minimization and controls

Provide only the text needed for the requested edit. Do not paste passwords, authentication codes, payment-card numbers, government identifiers, or private medical details. If sensitive information appears in text, redact it before sending it to the host model. The user controls whether to submit the text and can manage the conversation using the host product’s available controls.

## Contact

For this package, open an issue at [NomaDamas/k-skill](https://github.com/NomaDamas/k-skill/issues) with a synthetic example. Do not include private text or credentials.
