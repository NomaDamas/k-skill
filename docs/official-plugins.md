# 공식 플러그인 디렉터리용 번들

K-Skill의 전체 로컬 마켓플레이스 번들과 공개 플러그인 디렉터리용 번들은 범위가 다릅니다.

## 공개 디렉터리용

`packages/k-skill-directory/`의 `k-skill-korean-writing`은 사용자가 현재 대화에 직접 붙여 넣은 한국어 텍스트만 다루는 instruction-only 번들입니다.

- 실행 파일, hook, MCP, 프록시, 로그인, 파일 접근, 메일 접근, 백그라운드 작업, 분석 수집 없음
- 원문의 사실, 이름, 날짜, 수치, 인용문, 주장 강도, 높임말을 유지
- 비밀번호, 인증 코드, 결제카드 번호, 정부 식별번호, 비공개 의료 정보는 다시 출력하지 않음
- 공개 디렉터리 제출용 개인정보처리방침과 이용약관을 별도로 제공

이 번들은 Claude와 OpenAI의 공개 디렉터리 제출을 위한 최소 범위입니다. 공개 디렉터리 검토가 완료되기 전에는 등재나 승인으로 표시하지 않습니다.

## 전체 K-Skill

전체 K-Skill은 실행 helper, 공공 API와 프록시 연동, 로컬 자료 처리, 계정 연동, 예약/거래·법률·금융·의료 관련 기능을 포함할 수 있습니다. 이 범위는 자체 마켓플레이스와 사용자가 선택한 설치 환경에 둡니다. 공개 디렉터리용 번들에 전체 기능을 자동으로 합치지 않습니다.

## 변경 절차

정본 소스와 저장소 운영 규칙은 `AGENTS.md`, `CONTRIBUTING.md`를 따릅니다. 공개 범위를 넓히려면 해당 기능의 데이터 흐름, 인증, 제3자 약관, 사람 검토 경계를 먼저 별도 검토합니다.
