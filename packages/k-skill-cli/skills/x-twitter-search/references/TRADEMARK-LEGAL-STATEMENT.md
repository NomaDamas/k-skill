# 상표 사용 법적 고지: `x-twitter-search`

이 스킬은 `X`, `Twitter`, `Xquik` 명칭을 조회 대상과 호환 API를 식별하는 데만 사용한다. k-skill의 출처를 X Corp. 또는 Xquik으로 표시하지 않는다.

대법원 2005. 6. 10. 선고 [2005도1637 판결](https://www.law.go.kr/LSW/precInfoP.do?precSeq=83920)은 기능 설명용 표장과 출처 표시를 구별했다. [상표법 제2조](https://www.law.go.kr/법령/상표법/제2조), [제89조](https://www.law.go.kr/법령/상표법/제89조), [제90조](https://www.law.go.kr/법령/상표법/제90조), [제108조](https://www.law.go.kr/법령/상표법/제108조)에 따른 출처 혼동 판단은 별도다.

이 명칭은 필요한 범위의 평문으로만 쓴다. 로고나 공식, 제휴, 후원, 승인, 인증, 파트너 표현은 쓰지 않는다. 각 상표의 권리는 해당 권리자에게 있다.

Xquik은 X Corp.와 관계없는 독립적인 제3자 서비스다. "Twitter"와 "X"는 X Corp.의 상표다.

전체 검토: [제3자 상표의 기능 설명과 호환 대상 표시 검토](https://github.com/NomaDamas/k-skill/blob/dev/docs/legal/trademark-use-review.md)
