# 의약품 안전 체크

## What this skill does

식약처 공식 OpenAPI를 **`k-skill-proxy` 경유**로 조회해 **의약품개요정보(e약은요)** 와 **안전상비의약품 정보**를 확인한다.

하지만 사용자가 증상이나 복용 상황을 말하면 **바로 단정하지 말고 먼저 되묻는다.**

- 본인/아이/임산부/고령자 여부
- 어떤 약을 이미 먹었는지 / 지금 먹으려는지
- 언제부터 얼마나 복용했는지
- 현재 증상, 기저질환, 알레르기, 복용 중인 다른 약
- red flag (`호흡곤란`, `의식저하`, `심한 발진`, `지속되는 구토/흉통`)

red flag 가 있으면 API 조회보다 **즉시 119·응급실·의료진 연결**을 우선한다.

## Legal boundary (약사법·의료법)

이 스킬은 **식약처 허가사항 조회 도구**다. 면책 문구를 덧붙이는 것만으로는 아래 금지선이 해제되지 않는다. 의료법 제27조제1항은 "의료인이 아니면 누구든지 의료행위를 할 수 없으며"라고 행위 자체를 금지하므로, 이용자가 동의했거나 "참고용"이라고 고지해도 구성요건이 없어지지 않는다. 따라서 완화 수단은 고지 문구가 아니라 **행위 범위 제한**이다.

| 근거 조문 | 이 스킬이 하면 안 되는 것 | 벌칙 |
|---|---|---|
| 의료법 제27조제1항 (무면허 의료행위 금지) | 증상 → 질환 진단·확진, 처방, 복용량 증감 지시, 처방약 중단 권고 | 의료법 제87조의2제2항제2호 5년 이하 징역 또는 5천만원 이하 벌금 (상해·사망 시 같은 조 제1항 가중) |
| 약사법 제23조제1항 (조제 금지) | 두 약을 섞거나 쪼개 먹는 방법 안내 등 조제에 해당하는 지시 | 약사법 제93조제1항제3호 5년 이하 징역 또는 5천만원 이하 벌금 |
| 약사법 제2조제12호 (복약지도 정의) | 약사의 개별 복약지도를 대체하는 맞춤 지도. 허가사항 원문을 **인용**하는 것은 여기에 해당하지 않는다 | — (직능 경계) |
| 약사법 제44조제1항 (약국개설자 아닌 자의 의약품 판매 금지) | 의약품 판매·양도·거래를 중개하거나 대신 구매하는 행위 | 약사법 제93조제1항제7호 5년 이하 징역 또는 5천만원 이하 벌금 |
| 약사법 제61조의2제1항 (불법판매 알선·광고 금지) | 해외직구·개인거래·비약국 판매처 링크 제공, 구매 경로 안내 | 약사법 제95조제1항제10호의2 |
| 약사법 제68조 (과장광고 금지), 같은 조 제6항 | 허가사항을 넘는 효능 단정, 전문의약품 홍보성 권유 | 약사법 제95조제1항제10호 1년 이하 징역 또는 1천만원 이하 벌금 |

조문 확인 기준: 약사법(법률 제21109호, 2026-06-21 시행), 의료법(법률 제21524호, 2026-04-07 시행).

참고: 약사법 제44조는 "의약품 판매" 조항이며 의약품 정보 제공을 금지하는 규정이 아니다. 실제 리스크는 (1) 증상 인터뷰가 진단·처방으로 넘어가는 의료법 제27조, (2) 구매 경로 알선인 약사법 제61조의2, (3) 허가사항을 넘는 효능 단정인 약사법 제68조 쪽에 있다.

### 안전한 범위 (그대로 해도 되는 것)

- 식약처 허가사항(e약은요·안전상비의약품) 원문을 **출처와 함께 인용**하고 요약한다.
- 허가사항에 적힌 상호작용·금기 문구를 그대로 보여주고, 해당 문구가 있는지 여부만 사실로 전달한다.
- 어떤 정보가 없는지(허가사항에 언급 없음)를 명시한다.
- red flag 시 119·응급실·의료진 연결로 즉시 전환한다.
- 판단이 필요한 지점을 약사·의사 상담 질문 목록으로 정리해 준다.

### 금지 (문구를 붙여도 허용되지 않는 것)

- "이건 A질환입니다", "이 약 드시면 됩니다", "반 알만 드세요", "그 약 끊으세요" 같은 진단·처방·용량 지시.
- 허가사항에 없는 조합을 "괜찮다/안전하다"고 단정하는 것. 근거 문구가 없으면 "허가사항에 언급 없음, 약사 확인 필요"로 끝낸다.
- 의약품 구매처·해외직구·개인거래 링크 제공이나 구매 대행.
- 전문의약품을 권유하거나 효능을 홍보하듯 서술하는 것.

### 건강정보 취급

- 증상·기저질환·복약이력은 「개인정보 보호법」 제23조 민감정보다. 대화 맥락 안에서만 사용하고 파일·로그로 저장하지 않는다.
- helper 의 `lookup` 은 **제품명만** 프록시로 전송한다. 증상·병력을 쿼리 문자열에 넣지 않는다.

## When to use

- "이 약이랑 이 약 같이 먹어도 되니?"
- "타이레놀 먹는 중인데 판콜 같이 먹어도 돼?"
- "두드러기가 있는데 이 약 계속 먹어도 되나?"
- "식약처 공식 약 정보로 효능/주의사항 확인해줘"

## Prerequisites

- 인터넷 연결
- `python3`
- `@nomadamas/k-skill` CLI에 번들된 `scripts/mfds_drug_safety.py` helper
- `k-skill-proxy`의 `/v1/mfds/drug-safety/lookup` route가 있는 hosted/self-host 프록시에 접근 가능할 것

## Credential requirements

- 사용자 측 **필수** 시크릿 없음.
- `KSKILL_PROXY_BASE_URL` — self-host·별도 프록시를 쓸 때만 설정. 비우면 기본 hosted `https://k-skill-proxy.nomadamas.org` 를 사용한다.
- `DATA_GO_KR_API_KEY` 는 **프록시 운영 서버** 환경에만 둔다.

## Mandatory interview first

증상/복용상황이 언급되면 바로 결론을 말하지 말고 먼저 되묻는다.

권장 첫 질문 예시:

- `누가 복용하려는지(본인/아이/임산부/고령자), 이미 먹은 약 이름, 언제 얼마나 복용했는지, 지금 있는 증상을 먼저 알려주세요.`
- `호흡곤란, 의식저하, 입술·혀 붓기, 심한 전신 발진이 있으면 즉시 119 또는 응급실로 가야 합니다.`

## Official surfaces

- 공공데이터포털 문서: `https://www.data.go.kr/data/15075057/openapi.do`
- e약은요 endpoint: `https://apis.data.go.kr/1471000/DrbEasyDrugInfoService/getDrbEasyDrugList`
- 공공데이터포털 문서: `https://www.data.go.kr/data/15097208/openapi.do`
- 안전상비의약품 endpoint: `https://apis.data.go.kr/1471000/SafeStadDrugService/getSafeStadDrugInq`
- 프록시 route: `GET /v1/mfds/drug-safety/lookup`

## Workflow

1. 증상/복용상황이 있으면 인터뷰를 먼저 진행한다.
2. red flag 가 하나라도 있으면 즉시 응급 안내로 전환한다.
3. 약 이름이 확인되면 `k-skill-proxy`의 `/v1/mfds/drug-safety/lookup` 으로 공식 정보를 조회한다.
4. 효능, 사용법, 주의사항, 상호작용, 이상반응, 보관법을 허가사항 원문 기준으로 짧게 정리한다.
5. `같이 먹어도 되나?` 질문에는 공식 상호작용 문구만 근거로 제시한다. 해당 조합에 대한 문구가 없으면 "허가사항에 언급 없음"이라고 밝히고 안전하다고 단정하지 않는다.
6. 마지막에 약사·의사에게 물어볼 질문 목록과 함께, 최종 판단은 약사·의료진의 몫임을 명시한다.

## CLI examples

```bash
npx -y @nomadamas/k-skill@0 exec mfds-drug-safety scripts/mfds_drug_safety.py -- interview \
  --question "타이레놀이랑 판콜 같이 먹어도 되나요?" \
  --symptoms "두드러기와 어지러움"
```

```bash
npx -y @nomadamas/k-skill@0 exec mfds-drug-safety scripts/mfds_drug_safety.py -- lookup --item-name "타이레놀" --item-name "판콜"
```

## Response policy

- 이 스킬은 **진단/처방/복용 지시**를 하지 않는다 (의료법 제27조제1항).
- 공식 허가사항에 있는 효능/주의/상호작용 문구만 근거로 요약하고, 어떤 항목의 인용인지 밝힌다.
- 허가사항에 근거 문구가 없으면 추론으로 메우지 않고 "언급 없음 + 약사 확인 필요"로 답한다.
- 상호작용 문구가 모호하거나 red flag 가 있으면 약사·의사 상담으로 넘긴다.
- 증상이 있는 질문은 인터뷰 없이 바로 답하지 않는다.
- 의약품 구매·판매 경로는 안내하지 않는다 (약사법 제44조제1항, 제61조의2제1항).
- 허가사항을 넘는 효능 단정이나 전문의약품 권유를 하지 않는다 (약사법 제68조).
- 위 경계는 면책 문구로 대체되지 않는다. 문구를 덧붙이는 대신 답변 범위를 지킨다.

## Done when

- 증상 또는 복용상황을 먼저 되물었다.
- red flag 여부를 확인했다.
- 프록시 route를 통해 공식 endpoint 조회 결과를 JSON으로 정리했다.
- 최소한 제품명, 업체명, 효능/주의/상호작용이 포함된 요약을 제공했다.
- 허가사항에 근거가 없는 부분은 단정하지 않고 "언급 없음"으로 표시했다.
- 진단·처방·복용량 지시, 구매 경로 안내가 답변에 포함되지 않았다.
