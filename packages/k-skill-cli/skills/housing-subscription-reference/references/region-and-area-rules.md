# 청약 지역·면적 기준 (민영주택 청약 예치금)

## 출처와 검토일

- 1차 권위: 「주택공급에 관한 규칙」 (국토교통부령 제1592호, 시행 2026-06-15) — 국가법령정보센터(law.go.kr).
  - 별표 1 「가점제 적용기준」(개정 2024-12-18): 무주택기간·부양가족수·주택청약종합저축 가입기간.
  - 별표 2 「민영주택 청약 예치기준금액」(개정 2023-05-10): 지역·전용면적별 예치금.
- 검토일: 2026-10-30. 이 문서의 값은 위 법령 별표를 옮긴 정적 참고값이며, 최신 법령·입주자모집공고가 항상 우선한다.

## 지역 구분 (별표 2의 “지역” 열)

별표 2 비고: “지역”은 **입주자모집공고일 현재 주택공급신청자의 주민등록표에 따른 거주지역**을 말한다. 즉 **신청자의 주민등록상 거주지역**으로 구분하며, 공급(분양) 사업지의 소재지가 아니다.

| 코드(CSV 열) | 정의 | 해당 지역 |
| --- | --- | --- |
| `seoul_busan` | 특별시 및 부산광역시 | 서울특별시, 부산광역시 |
| `other_metropolitan` | 그 밖의 광역시 | 인천광역시, 대구광역시, 광주광역시, 대전광역시, 울산광역시 (정확히 이 5개) |
| `other_city_county` | 특별시 및 광역시를 제외한 지역 | 세종특별자치시, 제주특별자치도, 강원특별자치도, 전북특별자치도 및 도 관할 시·군 등 위 두 등급에 속하지 않는 모든 지역 |

- `other_metropolitan`은 “광역시”라는 명칭의 5개 도시만 해당한다. 세종특별자치시는 특별자치시이지 광역시가 아니므로 `other_city_county`에 속한다.
- 제주특별자치도·강원특별자치도·전북특별자치도는 특별자치도이지 특별시·광역시가 아니므로 `other_city_county`에 속한다.
- 질문의 지역이 모호하면(예: “광역시”) 어느 도시인지 먼저 확인한다.

## 전용면적 구간 (반개구간 [이상, 미만))

예치금은 “공급받을 수 있는 주택의 전용면적” 구간에 대응한다. 구간은 다음 반개구간으로 해석하며, 경계값은 아래 표와 같이 상한 포함(≤)·하한 초과(>)로 나눈다.

| 구간 | CSV `housing_area` | 85㎡ | 102㎡ | 135㎡ |
| --- | --- | --- | --- | --- |
| (0, 85] | `85sqm_or_less` | 포함 | | |
| (85, 102] | `102sqm_or_less` | | 포함 | |
| (102, 135] | `135sqm_or_less` | | | 포함 |
| (135, ∞) | `all_areas` | | | |

예: 85.0㎡는 `85sqm_or_less`, 85.01㎡는 `102sqm_or_less`.

## 예치금 표 (단위: 만원, KRW 10,000)

| 전용면적 | `seoul_busan` | `other_metropolitan` | `other_city_county` |
| --- | ---: | ---: | ---: |
| 85㎡ 이하 (0, 85] | 300 | 250 | 200 |
| 102㎡ 이하 (85, 102] | 600 | 400 | 300 |
| 135㎡ 이하 (102, 135] | 1,000 | 700 | 400 |
| 모든 면적 (135, ∞) | 1,500 | 1,000 | 500 |

## 계산 예시 (QA 기준)

- 무주택기간 10년 + 부양가족 2명 + 청약통장 가입기간 1년 → 22 + 15 + 3 = **40점** (최대 84점).
- 만 30세 미만 미혼 무주택자(유주택자 포함) → 무주택기간 **0점**.
- 청약가점 최대 합계 → 32 + 35 + 17 = **84점**.
- 세종특별자치시 거주, 전용 84.9㎡ (`85sqm_or_less`, `other_city_county`) → **200만원**.
- 서울특별시 거주, 전용 85.01㎡ (`102sqm_or_less`, `seoul_busan`) → **600만원**.

## 범위 밖

- 실제 단지의 당첨 커트라인·경쟁률·당첨 가능성 판단은 이 참고자료의 범위가 아니다.
- 국민주택(공공주택)의 청약 자격·순위·예치금은 별도 규정이며 이 자료는 민영주택 일반공급 기준만 다룬다.
- 최종 판단은 입주자모집공고문과 청약Home, 최신 법령을 따른다.
