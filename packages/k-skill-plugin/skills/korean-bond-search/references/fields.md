# SEIBro 필드 정규화

helper는 공백·괄호·대소문자를 정리한 뒤 아래 별칭을 인식한다. 인식하지 못한 필드는 `raw`에 남긴다.

| Canonical | 대표 원천 헤더 |
| --- | --- |
| `isin` | ISIN, 종목코드, 표준코드 |
| `name` | 종목명, 채권명 |
| `issuer` | 발행자, 발행사, 발행기관 |
| `bond_type` | 채권분류, 채권유형 |
| `currency` | 발행통화, 통화 |
| `issue_date` | 발행일 |
| `maturity_date` | 만기일, 상환일 |
| `coupon_rate_pct` | 표면금리, 이율, 쿠폰금리 |
| `coupon_type` | 이자지급방식, 금리유형 |
| `issue_amount_krw` | 발행금액, 발행액 |
| `outstanding_amount_krw` | 발행잔액, 잔액 |
| `offering_type` | 공모/사모, 모집방법 |
| `seniority` | 선후순위, 변제순위 |
| `guarantee` | 보증/무보증, 보증구분 |
| `listed` | 상장여부, 상장일 |
| `option_schedule` | 옵션일정, CALL/PUT 일정 |

ISIN은 12자리 형식과 국제 체크디지트를 검증한다. 입력 레코드의 체크디지트가 맞지 않거나 발행일이 만기일보다 늦으면 자료를 파싱 오류로 중단한다.

## 단위

- `3.25%`, `3.25` → `3.25`
- `1,500억원` → `150000000000`
- `1.2조원` → `1200000000000`
- `1억 5천만원` → `150000000`
- `1천만원` → `10000000`
- 헤더가 `발행금액(백만원)`이고 값이 `1500`이면 → `1500000000`
- `325bp` → 표면금리 `3.25`
- 단위 없는 금액 숫자는 원 단위로 해석한다. 숫자·단위를 일부만 파싱할 수 있는 문자열은 오독하지 않도록 미확인으로 둔다.
- 금액의 canonical 필드는 KRW이므로 `발행통화`가 명시적으로 `KRW`일 때만 채운다. 외화 또는 통화 미확인 금액은 원화로 재표시하지 않는다.
- 날짜는 `YYYY-MM-DD`, `YYYY.MM.DD`, `YYYY/MM/DD`, `YYYYMMDD`만 변환한다.

## 옵션·주식관련채

- 발행사/제3자의 `매도청구권`, `콜옵션`, `CALL`이 확인되면 `callable: true`
- 사채권자의 `조기상환청구권`, `풋옵션`, `PUT`이 확인되면 `putable: true`
- `상환청구권`만으로 권리 주체나 조기상환 여부가 확인되지 않으면 CALL/PUT을 추정하지 않는다.
- 옵션 필드에 옵션 없음이 명시되면 CALL과 PUT은 `false`; 옵션 필드 자체가 없으면 `null`. 다른 옵션 일정과 충돌하면 `null`로 둔다.
- `전환사채`/`CB`, `교환사채`/`EB`, `신주인수권부사채`/`BW`는 각각 별도 필드로 표시한다.
- 약어는 독립 토큰일 때만 인식한다. 회사명 일부 문자열과 우연히 겹친 경우는 판정하지 않는다.
- `채권분류=일반회사채`는 넓은 분류이므로 plain bond 또는 CB/EB/BW 부재를 뜻하지 않는다. `주식관련` 필드가 비었거나 옵션 일정이 없다는 이유만으로 세 구조를 `false`로 바꾸지 않는다.
- 세 구조가 요청의 핵심인데 SEIBro 명칭·주식관련 권리 정보로 확인되지 않으면 정확한 종목의 DART 발행결정 원문을 보조 확인한다. 원문도 확인할 수 없으면 `null`/사용자 답변의 `미확인`을 유지한다.
