# 계산·검증 방법론

## 데이터 정의

- 출처: 한국은행 ECOS 통계표 `817Y002` 시장금리(일별)
- 항목: 국고채 2년 `010195000`, 3년 `010200000`, 5년 `010200001`, 10년 `010210000`, 20년 `010220000`, 30년 `010230000`
- 정책금리 갭: 한국은행 기준금리 `722Y001/0101000`
- 단위: 연%
- 결과의 성격: 공식 일별 통계. 실시간 체결가 또는 개별 지표채 호가가 아니다.

## 날짜 정렬

각 요청일 이전에서 여섯 만기 값이 모두 존재하는 가장 최근 날짜를 공통 관측일로 사용한다. 기본 최대 지연은 주말과 한국 장기 연휴를 포괄하는 7일이며 설정 가능 범위는 0~14일이다. 전일 비교는 달력상 전일이 아니라 최신 공통 관측일 직전의 공통 관측일을 사용한다. 현재와 비교 기준이 같은 공통 관측일로 귀결될 때도 변화 계산을 차단한다.

대시보드는 최신 관측일, 직전 관측일, 7일 전 기준, 직전 월말 기준을 한 번에 계산한다. 분기말은 현재 분기의 직전 분기 말, 연초 대비는 전년도 마지막 공통 관측일을 기준으로 한다. 이벤트 비교는 이벤트 직전 마지막 공통 관측일과 이벤트 당일 또는 이후 첫 공통 관측일을 사용한다. 월 범위의 종료 월이 현재 진행 중이면 종료 기준일을 KST 오늘로 제한하고 최신 공통 관측일을 선택한다.

## 원천 검증

ECOS 응답마다 통계표 `817Y002`, 통계명 `1.3.2.1. 시장금리(일별)`, 항목코드·항목명, 단위 `연%`, 관측일 범위, 전체 건수와 실제 행 수를 확인한다. 원문 SHA-256은 evidence의 원문과 대조하고, 영수증의 건수·최초일·최종일은 정규화 관측치와 다시 대조한다. 캐시는 동일 만기·동일 조회 구간·168시간 이내인 경우에만 사용하며 캐시 봉투와 원문을 별도의 SHA-256으로 검증한다.

사용자 CSV는 `USER_CSV`와 파일명으로 별도 표시한다. ECOS에서 직접 수집하지 않은 입력에 한국은행 공식 원천 링크나 ECOS 통계표 식별자를 부여하지 않는다. 실시간 원자료 검증 후 로컬 캐시 저장만 실패한 경우 정상 관측값을 버리지 않고 결과에 캐시 저장 경고를 남긴다.

## 계산

- 만기별 변화(bp) = `(현재 연% − 비교 연%) × 100`
- 장단기 스프레드(bp) = `(장기 연% − 단기 연%) × 100`
- 스프레드 변화(bp) = `현재 스프레드 − 비교 스프레드`
- 정책금리 갭(bp) = `(국고채 3년 − 한국은행 기준금리) × 100`

기본 구간은 5년−3년, 10년−5년, 10년−3년, 30년−10년이다. 최근 5·20거래일 모드는 만기별 시작·종료, 고점·저점, 순변화와 절대값 기준 최대 일간 변동을 계산한다.

원자료로 계산한 뒤 출력 단계에서 표시 자릿수를 반올림한다.

## 곡선 분류

3년과 10년 변화 방향 및 10년−3년 스프레드 변화로 분류한다. 두 만기가 같은 폭으로 움직이면 평행 상승·하락으로 처리한다. 서로 반대 방향이면 혼합 움직임으로 표시하며 bull/bear 네 유형에 억지로 넣지 않는다.

## 재현성 경계

재현성이 뜻하는 것은 저장된 `evidence.mjson`을 같은 엔진 버전으로 처리했을 때 CSV·Markdown·HTML·상태 파일이 동일한 바이트로 생성된다는 것이다. 향후 ECOS 원자료가 수정되거나 신규 관측치가 추가되어도 새 조회 결과가 과거 실행과 같음을 보장하지 않는다.

주요 일정도 저장된 공식 일정 증거를 재생할 때만 동일하게 나온다. 일정 증거에는 확인한 원문 일부, 원문 날짜 표현, 공식 URL과 확인 UTC를 남긴다. 엔진은 날짜·만기·출처 호스트·입찰표의 Auction Date 위치를 검증하지만, 원문 페이지가 이후 수정되었는지는 재생 시 자동으로 확인하지 않는다. 최신 일정을 말할 때는 공식 원문을 다시 열어 확인한다. 일정 확인 실패는 금리 분석 상태를 변경하지 않으며 `UNVERIFIED`로 표시한다.

## 뉴스 evidence와 시장 배경

뉴스는 helper가 상시 크롤링하지 않는다. 에이전트가 공개 검색 결과와 원문 페이지를 확인한 뒤 제목, HTTPS 링크, 게시 UTC, 짧은 의역, 관측 방향과 관계 분류만 `news-evidence.json`에 기록한다. 기사 본문 전체를 저장하거나 재배포하지 않는다.

기사의 KST 게시일은 현재 공통 관측일과 같아야 한다. 3년과 10년 금리가 모두 상승하면 `higher`, 모두 하락하면 `lower`, 방향이 엇갈리면 `mixed`, 모두 보합이면 `flat`으로 정한다. 기사가 요인을 금리 움직임과 직접 연결한 경우에만 `explicit`으로 분류한다. 공식 발표나 같은 날의 관련 이벤트는 `contextual`이며 직접 원인 문장으로 사용하지 않는다.

같은 날 연합인포맥스 마감 기사에서 직접 설명하고 방향이 일치하면 `HIGH`, 그 밖의 일치 기사 하나는 `LOW`, 서로 다른 호스트의 복수 근거가 일치하면 `MEDIUM`으로 표시한다. 관측 방향과 다른 기사는 삭제하지 않고 `excluded`로 남긴다. 뉴스의 상태와 실패는 ECOS 커브의 `READY/INCOMPLETE/BLOCKED` 판정을 바꾸지 않는다.

각 기사 fingerprint는 정규화한 매체, 제목, URL, 게시시각, 유형, 방향, 관계, 요인과 근거 요약의 SHA-256이다. 이 fingerprint와 전체 `evidence.mjson` 및 manifest 해시를 함께 검증하므로 저장된 뉴스 코멘트도 replay에서 동일하게 생성된다.

## 산출물 게이트

스테이징 디렉터리에서 모든 파일을 만든 후 다음을 확인하고 최종 디렉터리로 이동한다.

- evidence SHA-256과 manifest 일치
- 각 산출물 SHA-256 일치
- evidence 재계산 상태와 manifest 상태 일치
- Markdown·CSV·HTML을 evidence에서 다시 렌더했을 때 동일
- 출력에 `NaN` 또는 `undefined` 없음
- 뉴스 사용 시 모든 채택·맥락·제외 출처와 fingerprint가 HTML·Markdown·상태 파일에 보존됨
