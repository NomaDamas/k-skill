# 모닝 브리핑 작성·검증 규칙

`multi-asset-morning-briefing`이 본문을 쓰기 전에 따르는 세부 규칙이다. 우선순위는 **정확성 > 출처 품질 > 관련성 > 간결성 > 서사**다.

작성 순서는 **Data first. Interpretation second. Outlook last.** 이고, 확인되지 않은 정보로 문서를 채우지 않는다.

## 1. 기준시점과 세션 (Temporal rules)

브리핑 기준일 `D`는 서울시간 오늘이고 제목 날짜도 `D`다.

- 미국 오버나잇과 한국 전일은 공식 관측일로 각각 확인한다. 달력상 `D-1`을 공통 적용하지 않는다.
- 미국 휴장과 한국 휴장이 다르면 두 세션 날짜가 달라도 정상이다.
- 일요일·월요일에는 토요일을 세션으로 만들지 않고 각 시장의 직전 완료 거래일을 사용한다.

수집한 값의 **관측일이 목표 세션과 같은지 먼저 확인**한다. 공식 집계 사이트는 시리즈별 발표 지연이 있어 FX·원자재·수급 데이터가 며칠 뒤처질 수 있다. 관측일이 다르면 그 값을 해당 세션 값처럼 쓰지 않는다.

자산군별 기준:

| 자산군 | 기준 |
| --- | --- |
| 미국 주식 | 정규장 종가. regular close와 after-hours를 섞지 않는다. ADR도 같은 미국 정규장 기준 |
| 미국 금리 | 2Y와 10Y를 **같은 공급자·같은 기준시점**으로 맞춘다. 서로 다른 공급자나 다른 시각으로 curve를 만들지 않는다. Treasury CMT와 market closing yield를 같은 데이터로 취급하지 않는다 |
| FX | DXY와 G10 FX는 같은 NY 기준시점. USD/KRW는 서울 현물 종가와 1M NDF를 구분하고 같은 시점처럼 쓰지 않는다 |
| 원자재 | WTI와 Brent를 같은 session의 settlement 또는 같은 성격의 close로 맞춘다. intraday high/low와 settlement를 구분한다 |
| 한국 | KOSPI·KOSDAQ·국내 채권은 서울시장 종가. KOSPI200 야간선물은 야간 session임을 밝힌다 |

미국 현물시장이 휴장한 날에는 현물 지수 종가 대신 선물이나 다른 자산군을 쓰고 휴장 사실을 명시한다. 휴장일 데이터를 정규장 종가처럼 표기하지 않는다.

## 2. 출처 정책 (Source policy)

데이터 종류별로 가장 적합한 원천을 쓴다. 모든 데이터에 같은 서열을 적용하지 않는다.

**가격 데이터**

1. 해당 거래소·공식 benchmark·시장 원천
2. 신뢰 가능한 전문 market data
3. 신뢰 가능한 데이터 집계 서비스
4. 증권사 시황
5. Telegram / Blog

Telegram이나 Blog만으로 핵심 가격을 확정하지 않는다.

**경제지표·중앙은행**

1. 공식 발표기관 2. 중앙은행·정부기관 3. Reuters 등 주요 통신사 4. 경제 캘린더 서비스

예: Fed → Federal Reserve, US CPI → BLS, 한국은행 데이터 → BOK, 한국 물가 → 통계청.

**뉴스·이벤트**

1. Reuters 2. AP 등 주요 통신사 3. 공식 발표 4. 연합뉴스·연합인포맥스 5. 증권사 시황

Telegram은 discovery와 interpretation 용도로만 쓴다.

**한국**

KRX, 한국은행, 금융투자협회, 연합인포맥스, 서울 외환시장 전문 데이터를 우선한다.

**접근 실패 처리**

- 실시간 시세가 유료·제한되어 지연 호가나 집계값만 확보되면 `SECONDARY` 이하로 처리한다.
- JS 챌린지·로그인 벽이 있는 사이트는 조회 실패로 처리하고, 공식 정적 endpoint → 브라우저 런타임 → 웹 검색 순으로 대체한다.
- 조회 수단이 전혀 없으면 브리핑을 시작하지 않고 확보 실패를 보고한다. 학습 시점 기억이나 이전 브리핑으로 숫자를 채우지 않는다.
- 각 bullet의 직접 링크와 문장 안의 기준시점으로 출처를 역추적할 수 있게 한다.

## 3. 검증상태 판정

- `VERIFIED` — 공식·1차 원천에서 직접 확인했거나, 서로 독립인 원천 2개 이상에서 일치
- `SECONDARY` — 단일 2차 원천만 확보
- `CONFLICT` — 독립 원천 간 숫자 불일치
- `UNVERIFIED` — Telegram·Blog 등 비공식 원천만 확보했거나 기준시점을 확인할 수 없음

**독립 원천**의 정의: 같은 데이터 벤더나 같은 원본을 재배포한 관계가 아닌 원천. 동일 원본을 재배포한 두 매체는 1개 원천으로 센다.

집계 서비스 값을 공식 원천과 대조해 일치시키면 `VERIFIED`로 올릴 수 있다.

`CONFLICT`·`UNVERIFIED` 핵심 숫자는 최종 출력에 쓰지 않는다. `SECONDARY`는 중요도가 낮고 다른 원천이 없을 때만 제한적으로 쓴다.

## 4. 산술 검증 (Arithmetic)

모든 계산값은 원자료에서 다시 계산한다.

- `2s10s = 10Y − 2Y`
- `Δ2s10s = Δ10Y − Δ2Y`
- 반올림된 변화폭으로 정밀한 spread 변화를 만들지 않는다. 원자료가 있고 소수 1자리까지 보고할 때만 `−1.4bp` 같은 표현을 쓴다. 표시값이 `2Y +4bp`, `10Y +3bp`뿐이면 `약 1bp 축소` 정도로 쓴다.
- 상대성과는 `%p`로 쓴다. 예: `EWY −6.62%`, `EEM −2.73%` → 상대성과 `−3.89%p`.
- `%`와 `%p`를 구분하고, `bp`와 `%p`를 혼용하지 않는다.
- VIX는 포인트(pt)로 표기하고 `%`로 쓰지 않는다.

## 5. Curve 분류

같은 기준시점의 2Y·10Y 변화폭이 있을 때만 적용한다.

| 2Y | 10Y | 판정 |
| --- | --- | --- |
| ↑ | ↑ | 2Y 상승폭 > 10Y → Bear Flattening / 10Y 상승폭 > 2Y → Bear Steepening |
| ↓ | ↓ | 2Y 하락폭 > 10Y → Bull Steepening / 10Y 하락폭 > 2Y → Bull Flattening |
| ↑ | ↓ (또는 반대) | 네 가지를 억지로 적용하지 않고 `2s10s가 XXbp 확대/축소`로 직접 쓴다 |
| 변화 없음 | 변화 없음 | `2s10s 변화 없음` |

금리 방향을 확인할 수 있는데 `curve flattening` 같은 표현만 쓰지 않는다.

## 6. 섹션 작성 규칙

**주요 일정**

- 브리핑일부터 향후 한국 거래일 5개를 날짜순으로 다룬다.
- 모든 시각은 KST로 표기하고 원본 발표 시각을 괄호로 병기한다.
- 제3자 캘린더 HTML을 자동 파싱하지 않고 공식 기관 발표 일정을 우선한다.
- 발표가 끝난 항목은 결과값, 예정 항목은 예정 시각과 전월치·컨센서스를 쓴다. 발표 완료 항목을 예정처럼 쓰지 않는다.
- Stage 2 필터를 통과한 항목만 쓴다. 자리 채우기용 이벤트를 넣지 않는다.

**Summary**

본문 전체의 축약본이 아니다. 시장 전체를 설명하는 3~5개 핵심 narrative를 5~6개 bullet 이내로 정리한다. 포함 우선순위는 미국 주요 지수 결과 → 핵심 driver → 가장 큰 cross-asset move → 주요 sector rotation → 다음 정책·이벤트 리스크다. 세부 숫자는 각 섹션에서 설명한다.

**Rates**

데이터 밀도를 가장 높게 가져간다. 순서는 **Level → Change → Curve → Driver → Event**.

권장 형태:

```
• 미 국채 2년물 4.670%(+2.0bp), 10년물 5.000%(+3.0bp). 2s10s는 33.0bp로 1.0bp 확대되며 Bear Steepening
```

Fed pricing이 중요한 날에는 실제 확률을 쓰고, 국채 입찰이 중요하면 stop yield·tail/through·bid-to-cover·indirect bidder 중 검증된 수치만 쓴다. 입찰이 아직 실시되지 않았으면 결과처럼 쓰지 않는다.

**FX**

순서는 **Level → Change → Driver**. 방향만 쓰지 않는다.

- 나쁜 예: `달러 강세`
- 좋은 예: `DXY 99.48(+0.36%)로 상승`

여러 EM 통화를 확인하지 않았으면 `신흥국 통화 전반 약세`로 일반화하지 않는다.

**Commodity**

순서는 **Settlement → Daily Change → Intraday → Driver**. 예: `WTI $63.66(+0.9%), Brent $67.88(+0.2%)`. 당일 핵심 narrative와 관련 없는 상품은 생략한다. 모든 상품을 매일 채울 필요는 없다.

**Equity, Vol**

순서는 **Index → Sector → Theme Basket → Individual Stocks**. 주요 지수를 먼저 제시하고 sector·theme을 설명한 뒤, 같은 driver로 움직인 종목을 basket으로 묶는다. 종목 나열 자체를 목적으로 하지 않는다.

**한국 증시**

미국시장 내용을 그대로 반복하지 않는다. 한국 관련 overnight proxy(SOX, SK하이닉스 ADR, EWY, KOSPI200 야간선물, USD/KRW, 1M NDF, KTB 3Y·10Y)를 먼저 제시하고 그 뒤에 해석을 붙인다. USD/KRW는 서울 현물시장 종가 기준을 우선하고, KTB는 level과 일간 bp 변화로 쓴다. 미국 업종 상승을 근거로 한국 동일 업종 상승을 단정하지 않는다. `상대강세 여부 확인 가능` 수준을 넘는 전망은 추가 근거가 있을 때만 쓴다.

## 7. 한국 전이 채널

연결고리가 약하면 한국시장 섹션에 억지로 넣지 않는다.

- 반도체: SOX·Memory·AI Hardware → 삼성전자·SK하이닉스·국내 반도체 밸류체인
- 금리: UST Yield → 성장주 valuation·외국인 수급·국내 금리
- 환율: DXY·USDKRW → 외국인 수급·원화 민감 업종
- 유가: WTI·Brent → 국내 물가·정유·화학·항공·운송
- 중국: 중국 실물지표·CNH → 반도체·화학·철강·기계·원화

## 8. 금지 항목

1. 출처를 확인하지 못한 핵심 숫자를 쓴다.
2. 다른 사람이 작성한 브리핑을 데이터 원천으로 쓴다.
3. Telegram 숫자를 독립 검증 없이 쓴다.
4. 서로 다른 시점의 2Y와 10Y로 curve를 계산한다.
5. 서로 다른 시장 관례를 하나의 종가처럼 섞는다.
6. 반올림된 값으로 정밀한 spread 변화를 만든다.
7. 확인할 수 없는 숫자를 추정한다.
8. 경제일정을 채우려고 중요도 낮은 이벤트를 넣는다.
9. Rates를 정성적 설명만으로 쓴다.
10. 숫자 없는 방향성 표현(`달러 강세`, `유가 상승`, `반도체 약세`)만 쓴다.
11. curve 방향을 판정할 수 있는데 Bull/Bear를 생략한다.
12. 동시 움직임만으로 인과를 확정한다.
13. 미국시장 움직임을 한국시장 전망으로 기계적으로 변환한다.
14. Fact와 Outlook을 섞는다.
15. Summary와 본문에서 같은 내용을 반복한다.
16. 본문 내용을 마지막 체크리스트로 다시 반복한다.
17. 특정 증권사나 Telegram 채널의 문장 구조를 모방한다.
18. `주목할 필요`, `확인할 필요`, `경계감 확대` 같은 추상문장을 반복한다.
19. 데이터가 없는 자산에 내용을 억지로 만든다.
20. 출처가 충돌하는 숫자 중 원하는 값을 임의로 고른다.
21. 오류 가능성이 높은 정보를 문서 길이를 채우려고 유지한다.
22. 뉴스 제목만 보고 실제 가격 반응을 확인하지 않은 채 핵심 driver로 정한다.
23. market pricing과 확정된 정책결정을 같게 표현한다.
24. `AI 투자 중단`, `긴축 확정`처럼 근거보다 강한 표현을 쓴다.
25. 없거나 확인되지 않은 값을 그럴듯한 수치로 메운다.

## 9. 문체

기관투자가용 모닝 브리핑 문체로 쓴다.

- 각 bullet은 가능한 한 1~2문장
- 가격과 숫자를 문장 앞부분에, 해석을 숫자 뒤에
- 불필요한 접속어·같은 형용사 반복 금지
- 장황한 macro 설명, 논문식 문체, 과도한 결론문 금지
- 영어 금융용어는 실무에서 통용되는 경우 사용 가능
- 종목·시장 움직임은 구체적으로 쓴다
- 모든 bullet 끝에는 직접 근거가 되는 Markdown 링크를 붙인다.
- `~이다`, `~했다`, `~합니다`, `~보인다` 대신 명사형·요약형 종결을 사용한다.

좋은 예:

```
• 미 2년물 4.670%(+2.0bp), 10년물 5.000%(+3.0bp). 단기물 대비 장기물 상승폭이 커 2s10s는 33.0bp로 1.0bp 확대, Bear Steepening
```

나쁜 예:

```
• 다양한 거시경제적 불확실성이 복합적으로 작용하면서 시장 참가자들의 향후 정책경로에 대한 경계감이 확대되는 모습
```

## 10. 검증 실패 시 행동

필요한 데이터를 찾지 못하거나 검증에 실패하면 다음 순서를 따른다.

1. 다른 신뢰 가능한 원천에서 다시 확인한다.
2. 숫자 없이 사실 수준으로 표현할 수 있는지 판단한다.
3. 핵심 내용이 아니면 해당 bullet을 삭제한다.
4. 핵심 내용인데 검증되지 않으면 확인되지 않았음을 명시한다.

절대 추정값을 만들어 넣지 않는다.

## 11. 완료 조건

아래를 모두 만족해야 작성을 완료한다.

- 핵심 시장 숫자가 검증됨
- 기준시점이 일관됨
- Rates curve 계산이 검증됨
- 주요 driver가 실제 가격 움직임과 연결됨
- 한국시장 전이가 과도하게 추정되지 않음
- 중복·추상문장이 제거됨
- 출처를 역추적할 수 있음

**중요한 숫자는 정확하게, 중요한 변화는 명확하게, 해석은 필요한 만큼만.**
